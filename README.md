Neuro-Symbolic Spatial Forensics & AI Image Detector is a fully local, privacy-preserving pipeline designed to distinguish authentic camera captures from AI-generated (Diffusion/GAN) and manipulated images. Rather than relying solely on black-box classification, it decomposes images into micro-spatial forensic signals—Error Level Analysis (ELA), edge-masked sensor noise variance, 2D FFT spectral ratios, and EXIF hardware telemetry—calibrated through a deterministic rule engine with social-media recompression guards. Triggered forensic signatures retrieve domain-specific artifact profiles from a local ChromaDB vector RAG store, grounding a custom Ollama (qwen2.5vl:7b) vision-language model to verify macro-spatial physics (illumination vectors, shadows, specular reflections, and geometry) before issuing a structured JSON verdict.
